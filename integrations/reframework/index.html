Bring your in-game colors into Color Sync

Edit colors live with EMV / Lua Freecam, then transfer the edited slots with one copy and paste.

Download exporter v1.5 · Nexus Mods page

If EMV Engine and Lua Freecam are not set up yet, follow the EMV Engine and Lua Freecam setup video. Keep REFramework installed.

Once EMV and Freecam are ready

  1. Enable the exporter. Place its ZIP in Fluffy Mod Manager’s Games/SF6/Mods folder. Refresh the mod list, enable SF6 Color Sync - Freecam Exporter, then start SF6.
  2. Edit and copy. Open the character’s Materials editor before editing colors in EMV / Freecam. Under REFramework’s Script Generated UI, open SF6 Color Sync, click Refresh characters, select your character, and click Copy for Color Sync.
  3. Paste and save. Load your target mod ZIP or CMD in Color Sync and choose the active color you want to update. In section 2, open Import Freecam Colors, paste, preview, and apply. Export your CMD or mod ZIP to save the edits.

Supported colors

The exporter includes edited CustomizeColor RGBA vectors, including Change Multiple edits in EMV’s cached meshes. Runtime RGB values convert automatically to visual CMD colors. Matching supported slots become active. Named hair shader colors are omitted.

Choose any loaded CMD as your target. Import updates its matching material and color names. Unchanged colors and other shader settings are omitted. Missing or ambiguous matches appear in the preview.

For inactive Color 1 defaults, load the complete mod ZIP and use Color Sync’s direct editor or sync controls. Freecam imports that would activate those defaults are blocked before applying changes.

Open each mesh’s Materials editor that you want to include, including separate hair/head meshes. Copy scans the selected character’s current cache, including meshes opened since the last refresh. When character grouping is unavailable, refresh after opening another mesh, then select and export each mesh separately. Open EMV before editing so it can capture the original colors.

The selector shows character names, players, and costumes, for example P1 - Ingrid C2 (8 cached meshes). Names such as esf032 appear as Ingrid even when costume information is unavailable. Open both players’ Materials and refresh to list both. Copy exports only the selected entry’s edits. Unknown costumes are labeled as unknown, and unidentified players include a unique object identifier.

Clipboard and undo

To share colors from a loaded CMD, use Export Colors as String in section 2 of Color Sync. Generate or copy the active CMD’s current colors, including applied edits, then paste into Import Freecam Colors for your chosen target. Inactive slots are omitted.

If copying fails, use Ctrl+A / Ctrl+C in the exporter’s text box, or save its JSON file and use Load Export JSON. The file is saved to reframework/data/SF6ColorSync/colors.sf6freecam.json.

Undo Last Import restores the pre-import CMD, including earlier edits and active states. Later CMD changes make that undo unavailable.
